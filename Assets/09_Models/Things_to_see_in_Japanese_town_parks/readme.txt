README
=======

Package Name
------------
Things_to_see_in_Japanese_town_parks

Version
-------
v1.0

Author
------
NobleSavageLLC.

Description
-----------
This package provides a collection of 3D prefabs inspired by objects commonly found in Japanese town parks.  
Each asset is optimized for use in Unity and can be easily integrated into your project.  

Included Prefabs
----------------
- Drainage_Ditch.prefab
- Drainage_Ditch_With_Moss.prefab
- Drinking_Fountain.prefab
- Drinking_Fountain_With_Moss.prefab
- Grated_Drainage_Ditch.prefab
- Grated_Drainage_Ditch_With_Moss.prefab
- Stone_Pillar.prefab
- Stone_Pillar_With_Moss.prefab
- Street_Light_Off.prefab
- Street_Light_On.prefab

Demo Scene
----------
A sample demo scene is included to showcase how the assets can be placed and lit in a realistic environment.  
Street_Light prefabs include both ON and OFF versions for flexible usage.

Usage
-----
1. Import the package into your Unity project.  
2. Drag and drop prefabs into your scene.  
3. Adjust materials, lighting, and scale to match your project’s needs.
