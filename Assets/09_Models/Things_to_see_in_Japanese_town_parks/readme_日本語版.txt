README
=======

パッケージ名
------------
Things_to_see_in_Japanese_town_parks

バージョン
----------
v1.0

作者
----
NobleSavageLLC.

説明
----
このパッケージは、日本の街中や公園でよく見られる設備をモチーフにした 3D モデル集です。  
Unity 用に最適化されており、すぐにプロジェクトへ組み込んで利用することができます。  
苔のあるバージョンとないバージョンを同梱しており、リアルなシーン作成が可能です。  

同梱 Prefab
------------
- Drainage_Ditch.prefab
- Drainage_Ditch_With_Moss.prefab
- Drinking_Fountain.prefab
- Drinking_Fountain_With_Moss.prefab
- Grated_Drainage_Ditch.prefab
- Grated_Drainage_Ditch_With_Moss.prefab
- Stone_Pillar.prefab
- Stone_Pillar_With_Moss.prefab
- Street_Light_Off.prefab
- Street_Light_On.prefab

デモシーン
-----------
シンプルな環境に各プレハブを配置したデモシーンを同梱しています。  
Street_Light プレハブには点灯版（On）と消灯版（Off）の両方があり、発光マテリアルとライト挙動を確認できます。  

使い方
------
1. Unity プロジェクトにパッケージをインポートします。  
2. "DemoScene" を開いて、アセットの全体像を確認します。  
3. Prefabs フォルダからシーンにドラッグ＆ドロップして利用できます。  

要件
----
- Unity 2021.3 以降  
- Universal Render Pipeline（URP）推奨  

ライセンス
-----------
本アセットは、商用・非商用を問わず Unity プロジェクト内でご利用いただけます。  
ただし、モデル単体の再配布や転売は禁止されています。
